## Resumo da atividade

Nesta atividade, proposta pela matéria de Lógica de Programação e Algoritmos (LOPAL), foi explorada a organização de dados através de um array de objetos. 

## Primeiramente, o seguinte desafio foi proposto aos alunos:

### Crie um array chamado alunos com 5 objetos;


**Cada aluno deve ter:**
+ Nome;
+ Idade;
+ Disciplina Preferida;

Depois tente acessar:

+ O nome do primeiro aluno;
+ A disciplina preferida do último aluno;

### O desafio foi resolvido utilizando a seguinte estrutura:

```
let alunos = [{nome: " ", idade: "", disciplinaFav: " "}, // aluno 0
    {nome: " ", idade: " ", disciplinaFav: " "}, // aluno 1
    {nome: " ", idade: " ", disciplinaFav: " "}, // aluno 2 
    {nome: " ", idade: " ", disciplinaFav: " "}, // aluno 3
    {nome: " ", idade: " ", disciplinaFav: " "},]; // aluno 4
```
-------------------------------------------------------------------------------------------------

## Em seguida, mais quatro exercícios foram propostos: 

+ **Ex. 1** Crie um programa que leia 10 números inteiros e armazene em um vetor. Em seguida, calcule e exiba a soma apenas dos números pares contidos no vetor.  

+ **Ex. 2** Crie um programa que preencha automaticamente um vetor numérico com 7 números gerados aleatoriamente pelo computador e depois mostre os valores gerados.

+ **Ex. 3** Crie um programa que solicite ao usuário 10 números inteiros e armazene em um vetor. Depois, peça ao usuário para digitar um número e verifique quantas vezes esse número aparece no vetor.

+ **Ex. 4** Peça ao usuário para digitar 10 números e armazene em um vetor. Depois, crie um vetor removendo os valores duplicados. Exiba o vetor original e o vetor sem duplicatas. 

### Todos os exercícios foram resolvidos através de códigos feitos em Javascript no VS Code, e permitiram a aplicação prática das estruturas de dados com o uso de vetores.
